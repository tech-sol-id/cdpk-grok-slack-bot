# Knowledge Base CDPK HQ

Folder ini berisi seluruh basis pengetahuan resmi tim CDPK HQ dalam format Markdown (`.md`).

## Alur Kerja:
1. File dokumen mentah diletakkan di Google Drive kantor:
   `https://drive.google.com/drive/folders/1oF8gzaqV1UUdug08KlkKAPomjHsbRL4q`
2. Dokumen diekstrak dan dikonversi menjadi file `.md` bersih di folder ini.
3. Lakukan `git push origin main`.
4. Render akan otomatis mendeteksi perubahan dan memperbarui bot dalam ~30 detik.
5. Grok Slack Bot otomatis membaca seluruh file `.md` di folder ini sebagai acuan menjawab pertanyaan tim.
