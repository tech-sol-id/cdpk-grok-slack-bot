Domain Admin

Bisa di akses melalui link berikut :

Android Dispatcher
Android Dispatcher Tramigo adalah aplikasi berbasis Android yang berfungsi sebagai klien pengawas (dispatcher client) untuk sistem komunikasi Tramigo PTT/PoC. Aplikasi ini digunakan oleh operator atau admin untuk memantau, berkomunikasi, dan mengelola pengguna PoC secara real-time.

Command Center (Dispatcher)
Command Center Tramigo adalah platform berbasis web yang digunakan untuk manajemen dan pengawasan perangkat Tramigo PTT (Push-to-Talk). Platform ini memungkinkan pengelolaan komunikasi, pelacakan perangkat, dan pemantauan jaringan PoC secara lebih efektif, yang cocok untuk penggunaan di berbagai sektor seperti logistik, pertambangan, keamanan, dan banyak lagi.

DOMAIN ADMIN TRAMIGO

DOMAIN ADMIN
Domain Admin (Web Admin) yaitu dashboard online yang berfungsi sebagai pengelola untuk penambahan user, penambahan grup & melihat lokasi dari user pengguna Radio POC Tramigo.
Beberapa fitur yang di sediakan :
Menambah user pengguna.
Menambah grup komunikasi (seperti tipe grup Regular, Dispatcher atau Broadcast).
Melihat lokasi GPS dari pengguna Radio PoC.
Memantau status pengguna atau perangkat secara real-time.
Mengatur hak akses atau peran pengguna (admin, user, dispathcer, dll).

Akses Domain Admin	
Untuk dapat meng-akses Domain Admin klik link berikut :https://tram.poc.fi/xdm/domainadmin/login.php
Kemudian login dengan username & password yang di miliki.
Setelah login tampilan akan seperti berikut.

ADD NEW USER
Pada tampilan berikut Menu untuk menambahkan user baru.
Pada kolom berikut, di isi menyesuaikan keinginan dari pengguna.

ADD NEW GROUP
Pada tampilan berikut Menu untuk menambahkan Grup. Terdapat beberapa tipe grup, yaitu :
Regular (default) : Hanya pengguna yang di tambahkan ke grup oleh Administrator yang dapat bergabung dengan grup.
Dispatcher : hanya pengguna Dispatcher yang dapat berbicara dengan semua orang dalam grup. Pembicaraan pengguna non-dispatcher hanya akan di teruskan ke dispatcher.
Broadcaster : Dirancang sebagai saluran prioritas di mana hanya dispatcher dan manajer grup yang dapat mengirim pesan suara, terlepas dari peran anggota grup. Anggota grup dapat membalas dispathcer atau manajer menggunakan fungsi 1-1, yang menciptakan.


USERs
Pada tampilan berikut Menu untuk melihat User yang sudah di tambahkan pada Domain Admin.

MANAGE GROUP
Pada tampilan Menu berikut untuk melihat Grup yang sudah di buat.
Bisa menambahkan User pada Grup dengan menggunakan UID (User ID) dari User tersebut.

MASS PROVISIONING
Pada tampilan Menu berikut mempermudah Administrator menambahkan User & Grup dengan format CSV.Berikut Menu-Menu yang yang bisa di gunakan :
Add new push to talk users : Menambahkan Pengguna Push-to-Talk Baru dengan format CSV.
Edit users : Mengedit Pengguna dalam format CSV.
Delete push to talk users : Menghapus Pengguna Push-to-Talk.
Add users to groups : Menambahkan user ke grup dalam format CSV.
Download Location History : Untuk mengetahui Riwayat lokasi dari pengguna.
Purge groups : Menghapus grup kosong dan membersihkan grup yang ada dari pengguna yang dihapus.
ICCID Search : Mencari semua domain yang tersedia untuk ICCID atau Install-ID.
