2: Enrollment as Device Owner 
 
Obtain the SafeUEM DO Enrollment QR Code 
 
2.1. Enroll using Generic DO agent/Authorized DO agent 
This generic agent could manage all GMS certified/compatible Android devices. Authorized DO 
agents provide more detail features. 
* The QR Enrollment Code can be distributed to users via email, file sharing as required. 
 
2.2. Initiate Device Owner Enrollment 
To enroll the device in Device Owner (DO) mode, the device must be factory reset before 
beginning the installation.  
Generate the Device Owner (DO) enrollment QR code from the SafeUEM portal. You may select 
your device brand and model during the configuration process.

2. Device Management 
a. Device Groups 
Under Device Page → Group List → Devices (Root), you can create new groups, view sub-groups, 
list devices, enroll devices, search, send messages, reset passwords, bulk create groups, rename, 
delete, and view logs. 
 
 
b. Device Operations 
Click a device in a group to expand its operations panel. 
 
Operations include: view info, app list, rule list, send message, send script, locate device, tag 
device, rename, delete, reboot, factory reset, screenshot, remote control, remote file 
management, download docs, and view logs. 
 
Close the page to exit current device info view.
