Introduction
The duplex is an important device in two-way radio communication system(Repeater mode). It allows
the transmitter and receiver to use the same antenna without interference. It provides isolation between
the transmitter and receiver to prevent interference and allows for efficient use of the antenna.
It can be effectively ensuring normal communication and channel security and can be applied to busy
systems with multiple carriers.
