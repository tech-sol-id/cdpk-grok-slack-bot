Formulir pengiriman barang import

IMPORT

Kepabeanan

Bea Masuk

Tidak setiap barang kan dikenakan Bea Masuk, dapat dilihat dari HS Code pada website INSW

Bekerjasama dengan bagian Keuangan mengenai pembayaran Bea Masuk

Bagian Sales & Marketing harus mengetahui apakah barang2 yang dijual harus membayar bea masuk, tidak semuanya harus membayar bea masuk, pengenaan bea berkisar 5%, 10%, dan 15%  

HS Code

Semua barang yang diimport harus memiliki nomor HS Code (Harmonized System Code), akan tetapi sampai sekarang belum seragam seluruh dunia, bahkan untuk USA, menggunakan HTS Number (Harmonized Tariff Schedule Number), HS Code ini digunakan untuk menentukan Bea Masuk, PPh22, PPn Import, SNI dan LS bila ada  

Laporan Surveyor (LS) 

Pada import barang² tertentu, harus dibuat Laporan Surveyor yang diselenggarakan oleh Sucofindo atau Anyndia.

 Pembuatan LS harus sebelum pengiriman barang

Pemberitahuan Import barang (PIB)

PIB adalah rician barang-barang yang diimport beserta kewajiban yang harus dibayar, seperti: PPn Import, Bea Masuk, PPh22, Asuransi dan Freight, sebelum ini dibayar, barang-barang tidak dapat keluar dari pelabuhan laut/udara.

*Tidak termasuk untuk barang² yang tak berwujud

PPn Import

Setiap import barang akan dikenakan PPn Import sebesar 11% dan dapat dikompensasikan setelah dijual, pihak Sales & Marketing tidak perlu menambahkan pada harga barang, karena pengenaan PPn akan dilakukan pada penghitungan seluruh transaksi  

Pajak Penghasikan PPh Pasal 22

SNI (Standard Nasional Indonesia)

Pada import barang-barang tertentu, pemerintah mewajibkan untuk membuat SNI (Standard Nasional Indonesia). Untuk SNI tidak memungkinkan, karena biayanya besar sekali, team pemerintah harus mengunjungi pabrik produsen, biaya transport dan akomodasinya ditanggung oleh kita sedangkan yang kita import jumlahnya hanya sedikit
