SmartICS 
 
SmartICS adalah perangkat lunak client-server untuk akuisisi data 
telemetri dan kendali jarak jauh suatu perangkat dibidang teknik 
sipil. Suatu platform perangkat lunak SCADA/IoT untuk otomasi 
industri, telemetri, pemantauan, BMS, dan sistem IoT tanpa 
pemrograman, berbasis web teknologi, jumlah workstation dan user 
tak terbatas. 
 
 
 
 
 
 
 


--- Halaman 2 ---
Kelebihan smartICS: 
 
- 15 tahun pengalaman dalam otomasi untuk berbagai industri 
percepat dalam 3-4 kali 
 
- Pengembangan perangkat lunak tanpa pemrograman karena 
teknologi No-code 
 
- Akses Web ke platform untuk penggunaan data dan laporan jarak 
jauh melalui browser web biasa dari perangkat dan dari tempat mana 
saja 
 
- Biaya SmartICS didasarkan pada perangkat yang terhubung 
 
- Mengurangi biaya hingga 50% dengan solusi berbasis SmartICS untuk 
otomatisasi dan digitalisasi 
 
- Portal Web Aman untuk Akses Web ke sistem SCADA yang diinstal 
 
- Perpustakaan widget otomatis untuk membuat antarmuka khusus untuk 
semua parameter yang dipantau 
 
- Dukungan teknis ahli siap membantu Anda dengan solusi teknis 
untuk proyek Anda

Fungsi SmartICS : 
 
- Monitoring, kontrol dan manajemen data 
 
- Satu set tombol control untuk kontrol peralatan jarak jauh 
 
- Seperangkat widget untuk pemantauan dan visualisasi status 
peralatan (sensor, batang, indikator, grafik, skema mnemonik, 
dll.). online maps. 
 
- Akses web ke data dari berbagai perangkat (panel HMI, stasiun 
kerja, tablet)

Manfaat SmartICS: 
Tanpa kode  
- Pengembangan, konfigurasi, dan implementasi 3-4 kali lebih 
cepat dibandingkan dengan perangkat lunak SCADA tradisional.  
SmartICS lebih mudah dikuasai karena tidak memerlukan keterampilan 
pemrograman.  
 
- Pembuatan antarmuka otomatis dan penautan tag ke widget  
 
- Pustaka widget otomatis bawaan Sistem penyalinan perangkat, 
pengaturan, dan widget yang nyaman  
 
- Izin pengguna yang dapat disesuaikan dan kemampuan memiliki 
antarmuka terpisah untk setiap pengguna  
 
- Konfigurasi tanpa memerlukan keterampilan pemrograman dan skrip  
 
- Konfigurasi online melalui browser web tanpa lingkungan 
pengembangan terpisah  
 
Berbasis Teknologi Web Akses online ke semua data dari perangkat 
- Online akses dari semua device di jaringan perusahaan melalui 
browser web biasa. 
- Terapkan portal web dengan perangkat lunak SCADA pihak ketiga 
untuk semua pengumpulan data  
 
- SmartICS tidak memiliki lingkungan pengembangan berbayar yang 
terpisah

- Satu platform untuk mengakses data, tren, log, dan dashboard 
melalui browser web umum  
 
- Portal Web SmartICS dapat digunakan bersama dengan perangkat 
lunak SCADA pihak ketiga untuk pengumpulan data jarak jauh  
 
- SmartICS menggunakan protokol enkripsi untuk koneksi yang aman  
 
- Akses data cepat untuk operator dan layanan lainnya Pembuatan 
dashboard individual dan diferensiasi akses  
 
 
Tidak ada batasan jumlah tag dan pengguna 
- Lisensi terpadu tanpa batasan pada workstation operator, tag, dan 
pengguna. Hitung biaya proyek pada tahap desain sistem  
 
- Biaya lisensi SmartICS didasarkan pada:  
 
1) sejumlah unit yang diinterogasi, seperti PLC, RTU, penghitung, 
atau perangkat antarmuka cerdas lainnya  
 
2) protokol komunikasi yang disukai  
 
3) memiliki modul fungsional tambahan  
 
- Tidak ada risiko lupa menambahkan semua tag yang diperlukan atau 
membeli yang tambahan  
 
- Peluang untuk memperluas sistem anda tanpa batasan jumlah 
workstation dan pengguna jarak jauh
