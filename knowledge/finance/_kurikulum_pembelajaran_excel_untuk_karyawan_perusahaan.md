🎓 Kurikulum Pembelajaran Excel untuk Karyawan Perusahaan
🟢 Level 1: Beginner (Dasar-Dasar Excel)
⏱️ Durasi: 1–2 hari (2–4 jam/hari)


Tujuan: Memahami dasar penggunaan Excel untuk keperluan administrasi, entri data, dan format laporan.


Materi:
Pengenalan Excel Interface


Ribbon, cell, sheet, range


Navigasi & Shortcut Dasar


Input Data & Format Cell


Angka, teks, tanggal


Operasi Matematika Dasar


Penjumlahan, pengurangan, perkalian, pembagian


Penggunaan Fungsi Dasar


SUM, AVERAGE, MIN, MAX, COUNT


Membuat Tabel & Border


Sort & Filter Data


Pengenalan Conditional Formatting


Menyimpan & Mencetak File Excel


Tugas Akhir: Membuat Tabel dan Laporan Sederhana


🟡 Level 2: Intermediate (Pengolahan Data & Analisis Dasar)
⏱️ Durasi: 2–3 hari (2–4 jam/hari)


Tujuan: Mengolah data lebih kompleks, membuat laporan dan analisis dasar.


Materi:
Fungsi Logika & Teks


IF, AND, OR, IFS


LEFT, RIGHT, MID, LEN, TRIM, CONCATENATE


Lookup & Reference


VLOOKUP, HLOOKUP, XLOOKUP, INDEX, MATCH


Data Validation & Drop-down List


Penggunaan IFERROR dan IFNA


Pembuatan Grafik Dasar


Bar, Line, Pie Chart


Freeze Panes & Split Window


Pivot Table & Pivot Chart (Pengenalan)


Tugas Akhir: Laporan Dinamis dengan Grafik


🔵 Level 3: Advanced (Automasi & Analisis Data Lanjutan)
⏱️ Durasi: 2–4 hari (2–4 jam/hari)


Tujuan: Mampu menganalisis data besar, membuat laporan otomatis dan efisien.


Materi:
Advanced Pivot Table & Slicer


Fungsi Lanjutan:


SUMIFS, COUNTIFS, TEXTJOIN, UNIQUE, FILTER


Named Ranges & Dynamic Ranges


Conditional Formatting Dinamis


Data Cleaning dengan Power Query


Dashboard Mini Excel (Pengantar Visualisasi)


Macros & Pengenalan VBA


Simulasi Kasus: Laporan Penjualan, Inventaris, Absensi, dan KPI


Tugas Akhir: Dashboard Interaktif


🟣 Opsional: Specialized Training
Tergantung kebutuhan divisi/karyawan:


Excel untuk Keuangan (Neraca, Cash Flow, ROI)


Excel untuk HR (Absensi, Payroll, Headcount)


Excel untuk Inventory & Supply Chain


Excel untuk Sales & Marketing


📦 Format Pelatihan
Metode: Kelas langsung, online, atau blended learning


Tools: Google Sheets / Microsoft Excel 365 / Excel 2019


Evaluasi: Pre-test dan post-test, tugas per level


Sertifikat: Diberikan sesuai level yang diselesaikan
